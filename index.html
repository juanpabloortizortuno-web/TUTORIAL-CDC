Guía completa: Bot Desmayo

Cómo conectar Binance Futuros (API Key, Secret, IP), cómo usar TESTNET y cómo opera el bot paso a paso.

⬇ Descargar la guía en PDF↗ Abrir PDF
Aviso importante. El bot compra LONG en Futuros USDT-M, sin stop loss. Si la moneda sigue cayendo, la posición queda abierta hasta que suba. Con el modo emergencia (2x) una caída fuerte puede liquidar casi todo el margen. Usa solo dinero que puedas perder y practica primero en TESTNET. Esto no es asesoría financiera.

1. Cómo funciona todo

El CDC detecta monedas en DESMAYO o CAÍDA BRUTAL (y, si lo activas, DESMAYO INMINENTE). El bot las compra en LONG y deja puesta en Binance una orden de venta con tu ganancia objetivo. Todo ocurre desde tu navegador: las claves se guardan solo en tu dispositivo y se envían directo a Binance.

Reglas del bot

  • Solo LONG, margen aislado, apalancamiento 1x (2x en modo emergencia).
  • La salida es una orden límite reduce-only colocada en Binance; si tu opción «Ganancias NETAS» está marcada, descuenta comisiones.
  • No usa stop loss.
  • Una moneda cerrada no se vuelve a comprar hasta que el CDC dé una nueva alerta para ella.
  • Con capital chico (menos de 100 USDT) opera una moneda a la vez; si hay una operación abierta (incluida una tuya manual) el bot espera a que termine y no la toca.

2. Crear la API en Binance (paso a paso)

Requisito: tener la identidad verificada (KYC). Entra a Binance desde el navegador y sigue estos pasos.

Paso 1 · Abrir «Gestión de API»

Ruta: Panel de usuario → Cuenta → Gestión de API, o directo en binance.com/es-LA/my/settings/api-management. Arriba a la derecha está el botón amarillo «Crear API».

Paso 2 · Casilla «Controles de seguridad predeterminados»

Déjala MARCADA. Con ella marcada, Binance quita el permiso de trading a las claves sin IP restringida; por eso en el paso 6 restringiremos la API a tu IP.

Paso 3 · Elegir el tipo de clave

Elige «Generada por el sistema» (HMAC) y pulsa «Siguiente». La opción «Autogenerada» (Ed25519/RSA) no sirve para este bot.

Paso 4 · Ponerle nombre

Escribe una etiqueta, por ejemplo CDC-BOT, pulsa «Siguiente» y confirma la verificación de seguridad (código del correo, Authenticator o passkey).

Paso 5 · Copiar la API Key y el Secret

Binance muestra la Clave API (tu «usuario») y la Clave secreta (tu «contraseña», con la que el bot firma cada orden). Pulsa «Copiar» en cada una. El Secret se muestra una sola vez: si lo pierdes, borra esa API y crea otra. Nunca compartas el Secret ni lo muestres en capturas.

Paso 6 · Restricciones: primero la IP, después Futuros

Pulsa «Editar restricciones» y haz esto en este orden. Binance elimina la API si tiene un permiso distinto de lectura y no tiene IP restringida.

  • En «Restricciones de acceso IP» elige «Restringir el acceso solo para direcciones IP confiables».
  • Pega tu IP pública y confirma. El bot la muestra sola en el panel 📈 → pestaña 🔌 Conectar, con botón «Copiar IP».
  • Marca «Habilitar Futuros» (además de «Habilitar lectura») y guarda.
  • Deja desmarcados: retiros, trading de Margen/Acciones/Spot, préstamos y transferencias universales.
Si tu proveedor de internet cambia tu IP (por ejemplo al pasar de WiFi a datos móviles), el bot mostrará el error −2015 junto con tu IP actual: actualízala en Binance. El bot no puede agregarla solo, porque Binance no permite que una API edite su propia lista de IPs.

3. Conectar las claves al bot

  1. Abre el bot y toca el botón flotante 📈. Se abre el panel en la pestaña 🔌 Conectar.
  2. IP: aparece sola en la primera casilla (se vuelve a escanear al cambiar de red). Toca «Copiar IP» y pégala en Binance (paso 6).
  3. Copia la API Key en Binance y toca 📋 Pegar API Key; luego copia el Secret y toca 📋 Pegar Secret. Si el navegador no permite leer el portapapeles, mantén pulsado el campo y elige «Pegar».
  4. Revisa la casilla Usar TESTNET: con claves reales debe estar desmarcada (saldrá el aviso rojo «MODO REAL»); con claves de testnet, marcada.
  5. Toca 💾 Guardar y probar conexión. Debe decir «✅ Conexión OK» y mostrar tu capital.
Tus claves quedan guardadas en tu propio dispositivo: no tendrás que volver a escribirlas. La próxima vez el panel abre directo en el Monitor. Solo vuelven a pedirse si las cambias, si borras los datos del navegador o si hay un error de conexión.

5. Practicar con TESTNET (sin riesgo)

TESTNET es una copia de Binance Futuros con dinero de mentira. Sus claves son distintas a las de Binance real.

  1. Entra a testnet.binancefuture.com (web aparte).
  2. Revisa el saldo falso en USDT.
  3. Abajo, pestaña API Key: genera y copia la Key y el Secret de testnet.
  4. Pégalas en el bot y marca «Usar TESTNET» (el paso que más se olvida).
  5. Guardar y probar conexión → debe decir «✅ Conexión OK (TESTNET)».
  6. Pulsa ▶ RUN. Cuando el CDC marque un desmayo, el bot compra y pone la salida; míralo en Operaciones y Registro.
  • A veces la moneda en alerta no existe en testnet («no es perpetuo USDT-M operable»): espera otra alerta.
  • Con miles de USDT falsos el modo emergencia (< 6 USDT) no se activa en testnet.
  • Los resultados de testnet no son una promesa de lo que pasará con dinero real.

El simulador del CDC no usa tu cuenta ni TESTNET: guarda simulaciones en tu navegador con precios reales. TESTNET sí envía órdenes, pero con saldo falso. Sirven para cosas distintas y no comparten datos.

6. Usarlo como app en el celular

  • Instalar: en el panel 📈 → 🔌 Conectar toca «📲 Instalar como aplicación». En iPhone (Safari): Compartir ⬆ → «Añadir a pantalla de inicio».
  • Pantalla encendida: con el bot activo, la app pide mantener la pantalla encendida (casilla 🔆 en la tarjeta del bot).
  • Mantén la app abierta y visible. Una página web no puede seguir corriendo si bloqueas el celular o cambias a otra app: el bot se pausa. Las órdenes de salida ya puestas en Binance siguen activas.
  • La IP cambia entre WiFi y datos móviles. Si cambias de red, agrega la IP nueva en Binance; el panel te avisa.

7. Lista antes de encender el bot en real

  • API creada «Generada por el sistema» (HMAC), con Habilitar Futuros y sin retiros.
  • Acceso restringido a mi IP y cambios guardados en Binance.
  • Claves guardadas; «Usar TESTNET» desmarcada (real) o marcada (práctica) según corresponda.
  • «Guardar y probar conexión» dice OK y muestra mi capital.
  • USDT transferido a la billetera de Futuros USDⓈ-M; saldo ≥ 5 USDT para el mínimo de orden.
  • Cuenta en modo Single-Asset.
  • Probé antes en TESTNET y vi una compra con su salida.
  • Entiendo que no hay stop loss y que con 2x una caída fuerte puede liquidar el margen.
  • Solo uso dinero que puedo permitirme perder.
Seguridad: no compartas el Secret con nadie ni lo muestres en capturas; deja siempre los retiros desactivados; si sospechas que se filtró, borra la API en Binance y crea otra.
